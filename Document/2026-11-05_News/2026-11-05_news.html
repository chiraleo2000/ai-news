งานวิจัย 'You Don't Need Long Context' ชี้การบีบอัดบริบทแม่นยำเท่าเดิมแต่ถูกลงมาก

AI Weekly (citing arXiv/Hugging Face Papers) · Research · MEDIUM · BREAKTHROUGH · 2026-11-04T12:00

งานวิจัยชื่อ You Don't Need Long Context อ้างว่าโมเดลระดับ frontier สามารถได้ความแม่นยำเทียบเท่าบริบทยาวด้วยหน้าต่างบริบทที่สั้นกว่ามาก โดยใช้กลยุทธ์ compaction สองแบบ คือ End-of-Conversation Compaction และ Single-Action Compaction ความแม่นยำต่างจากการใช้ประวัติเต็มอยู่ในช่วง -3.7 ถึง +5.6 จุดเปอร์เซ็นต์ และประหยัดต้นทุนได้ 6.5-54.6 เท่าในงานอินพุตยาว งานนี้ระบุว่าการ generate ที่บริบท 256K แพงกว่า 16K ราว 3.6-7 เท่าบนโมเดล frontier และเสนอ Semantic State Space Models ที่เก็บสถานะภาษาธรรมชาติแบบกะทัดรัด ประเมินกับ Claude Opus 4.5, GPT-5.6 Sol, GLM 5.2, Kimi K2.6, Qwen และ Gemma 4 บน SWE-bench, Terminal-Bench 2.1, LongBench v2 และ LOONG ผู้สรุปข่าวแนะนำให้ตรวจตัวเลขกับเปเปอร์ต้นฉบับก่อนนำไปอ้างอิง

Impact: ถ้าผลยืนยัน การ compaction ช่วยลดต้นทุนเอเจนต์งานยาวได้หลายสิบเท่า แต่ตัวเลขจากข่าวสรุปยังต้องตรวจกับต้นฉบับ

Impact: เปลี่ยนมุมมองของ speculative decoding จากเครื่องมือเร่งความเร็วเป็นกลไกควบคุมคุณภาพเอเจนต์ แต่ยังไม่มีตัวเลขยืนยันในข่าวสรุป

Check Point พบ 'prompt adware' ซ่อนในชุด jailbreak ของ Codex ฝังโฆษณา LLM gateway

Check Point Research · International · HIGH · 2026-11-03T12:00

Check Point Research วิเคราะห์ชุด jailbreak ภาษาจีนชื่อ Haiou เวอร์ชัน 4.5.0 ที่มุ่งเป้า OpenAI Codex พบว่าชุดนี้ซึ่งมีมากกว่า 250 ดาวบน GitHub ประกอบด้วยไฟล์พรอมต์แบบโมดูลราว 31 ไฟล์ และ Skills ด้านความปลอดภัย 6 ชุด ทีมวิจัยเรียกแนวทางนี้ว่า prompt adware คือการแก้คำสั่งที่เอเจนต์เชื่อถือแบบถาวร โมดูล 00-identity.md สั่งให้เอเจนต์ตอบคำทักทายด้วยข้อความโฆษณา LLM gateway แบบเสียเงิน และโมดูลอีกตัวห้ามทดสอบเจาะ gateway ดังกล่าว ตัว payload ถูกเข้ารหัสและตรวจสอบด้วย Ed25519 กับ SHA-256 เพื่อเลี่ยงตัวสแกน ส่วนเวอร์ชันสำหรับ Claude Code ไม่มีการฝังโฆษณา และ Claude ตรวจพบว่าเป็น prompt injection นักวิจัยเตือนว่า LLM gateway เป็นความเสี่ยงซัพพลายเชน เพราะบางตัวแอบอ่านข้อมูล ขโมยความลับอย่างคีย์คลาวด์ หรือแทรกการเรียกเครื่องมือ

Impact: คำสั่งในไฟล์ config ของเอเจนต์กลายเป็นช่องทางโฆษณาและโจมตีซัพพลายเชนรูปแบบใหม่ นักพัฒนาที่ติดตั้งชุดพรอมต์จากภายนอกเสี่ยงถูกเปลี่ยนพฤติกรรมเอเจนต์

Developer
  • ตรวจสอบไฟล์ CLAUDE.md, AGENTS.md และ Skills ส่วนกลางว่ามีข้อความโฆษณาหรือคำสั่งแปลกปลอมหรือไม่
  • หลีกเลี่ยงชุด jailbreak/พรอมต์ภายนอกและตรวจ LLM gateway ที่ใช้งานทุกตัว
Business
  • กำหนดนโยบายอนุมัติ Skills และ prompt bundle ก่อนอนุญาตใช้ในองค์กร
