The Shared Discovery Paradox: How a One-Answer Rule Turns Better Information into Worse Search

Paradox นี้มีนัยสำคัญต่อการออกแบบ multi-agent system ทุกชนิด — sharing information เร็วเกินไปอาจเป็นอันตราย ต้องออกแบบ coordination mechanism ที่ balance exploration กับ exploitation Yohei Nakajima (BabyAGI creator) นำเสนองานวิจัยที่ discover paradox ใน multi-agent search: เมื่อ system ใช้ one-answer rule (agent ที่ค้นพบคำตอบแรกจะ share ทันทีและทำให้ agent อื่นหยุดค้นหา) การมีข้อมูลที่ดีขึ้นในแต่ละ agent กลับทำให้ search quality โดยรวมแย่ลง เพราะ early false positive มี cascade effect ที่รุนแรงขึ้น งานนี้มี code และ interactive guide ใน GitHub พร้อมใช้ มี implication ต่อ design ของ multi-agent RAG, parallel agent search, และ distributed knowledge systems

IMPACT: Shared Discovery Paradox เป็น fundamental finding ที่ designer ของ multi-agent system ต้องเข้าใจ — naive sharing คือ failure mode ไม่ใช่ feature
DEV ACTION: Review multi-agent search pipeline ว่ามี premature convergence risk จาก one-answer rule
BIZ ACTION: ถ้าใช้ multi-agent RAG หรือ parallel search ตรวจสอบว่า answer quality ถูก validate ก่อน propagate
