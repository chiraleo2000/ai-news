Can Agent Memory Systems Track Evolving State?

เมื่อ LLM agent ถูกใช้งานในบทสนทนาที่ยาวและซับซ้อนมากขึ้น ระบบความจำของ agent ยังมีช่องโหว่สำคัญคือไม่สามารถติดตามสถานะของโลกที่เปลี่ยนแปลงไปตามเวลาได้ดีพอ เมื่อข้อเท็จจริง เงื่อนไข หรือการตัดสินใจถูกแก้ไขระหว่างบทสนทนายาว คำตอบของ agent ควรสะท้อนสถานะล่าสุดไม่ใช่สถานะที่ถูกยกเลิกไปแล้ว ทีมวิจัยนิยามความสามารถนี้ว่า state tracking และสร้างเบนช์มาร์ก StateMemBench Qwen-3.5-9B นอกจากนี้ยังสามารถนำแนวคิดนี้ไปใช้เป็น wrapper น้ำหนักเบาครอบระบบความจำเดิมได้ ช่วยเพิ่มความแม่นยำได้ถึง 32-67 คะแนนในหลาย backend งานวิจัยนี้ชี้ให้เห็นช่องโหว่สำคัญของระบบความจำ LLM agent ที่มักถูกมองข้าม นั่นคือความสามารถในการติดตาม "สถานะที่เปลี่ยนแปลงไปตามเวลา" ของโลก ไม่ใช่แค่การจดจำข้อมูลในอดีต เบนช์มาร์กเดิมส่วนใหญ่เน้นงานที่มีลักษณะการ recall เท่านั้น
