GPT-6 Astra ของ OpenAI ช่วยไขโจทย์คณิตศาสตร์ที่ยากที่สุดของ Standard Model บน lattice

OpenAI's GPT-6 Astra tackles the Standard Model's toughest math problem on a lattice

Nathaniel Craig นักฟิสิกส์จาก UC Santa Barbara และนักวิทยาศาสตร์รับเชิญของ OpenAI เผยว่า GPT-6 Astra ช่วยพัฒนาวิธีนิยาม Standard Model ทั้งทฤษฎีบน lattice หรือโครงตาข่ายกาลอวกาศ ซึ่งทำไม่ได้มานาน เพราะแรงอย่างอ่อนปฏิบัติต่ออนุภาคมือซ้ายและมือขวาต่างกัน ทำให้เกิดอนุภาคผีที่ไม่ต้องการ แม้ overlap fermions จะกรองอนุภาคเหล่านี้ได้ แต่กว่า 25 ปีไม่มีใครกำหนดเฟสได้ถูกต้อง Craig เสนอแนวคิดเทียบ lattice ที่ละเอียดขึ้นเรื่อย ๆ แต่พิสูจน์ไม่ได้ครบ GPT-6 Astra จึงแปลงแนวคิดเป็นโครงสร้างที่ใช้งานได้และนำการพิสูจน์โดยละเอียด ผลงานผ่านการตรวจโดยผู้เชี่ยวชาญ lattice field theory สามคน และเผยแพร่บนบล็อก OpenAI กับ arXiv 2610.09093 ทั้งนี้ Craig ย้ำว่าเป็นเพียงจุดเริ่มต้น ยังต้องทำงานอีกมากก่อนจำลองได้จริง

Tech impact: ตอกย้ำแนวโน้ม AI เป็นผู้ร่วมวิจัยในคณิตศาสตร์และฟิสิกส์ระดับพรมแดนความรู้ แต่ยังต้องอาศัยการตรวจสอบโดยผู้เชี่ยวชาญมนุษย์

  • สร้าง pipeline ให้ผู้เชี่ยวชาญรีวิวผลลัพธ์จาก AI ก่อนนำไปใช้

Gamer: A Generalist Vision-Language-Action Foundation Model for Long-Horizon Real-Time Game Agent

ทีม Honkai AI R&D ของ miHoYo เผยแพร่งานวิจัย Gamer ซึ่งเป็นเฟรมเวิร์ก agent อเนกประสงค์แบบ Vision-Language-Action สำหรับงานระยะยาวในสภาพแวดล้อม 2D และ 3D โดยรวมการรับรู้ภาพ การจัดการหน่วยความจำ และการให้เหตุผลหลายขั้นไว้ในสถาปัตยกรรมเดียว โมเดลผ่านการ pre-train ต่อเนื่องด้วยข้อมูลการกดแป้นพิมพ์และเมาส์หลายหมื่นชั่วโมง ใช้ sparse-thinking instruction tuning เพื่อลดการคำนวณซ้ำซ้อน และใช้ reinforcement learning แบบหลายรอบที่เสถียร พร้อม inference engine แบบ cloud-edge ที่รองรับเกมจำนวนมากพร้อมกันด้วย latency ต่ำ ผู้เขียนอ้างว่ามีประสิทธิภาพใกล้เคียงผู้เล่นมีฝีมือในเกม open-world 3D หลายเกม โพสต์ของทีมระบุข้อมูลเกมเพลย์กว่า 10,000 ชั่วโมง คำอธิบายเหตุผลราว 1.2 ล้านรายการ latency ต่ำลงกว่า 20 เท่า และผ่านภารกิจหลักของ Honkai: Star Rail กว่า 95% ซึ่งยังเป็นตัวเลขที่ผู้เขียนรายงานเอง

Tech impact: แสดงว่าข้อมูลการควบคุมคอมพิวเตอร์ระดับคีย์บอร์ด-เมาส์ปริมาณมากสามารถสร้าง agent ทั่วไปได้ ต่อยอดสู่ computer-use agent และหุ่นยนต์

  • ทดลอง multi-turn RL สำหรับงานที่มี reward เบาบาง

MMFlash: เร่งความเร็ว speculative decoding สำหรับโมเดล Vision-Language ได้สูงสุด 3.58 เท่า

MMFlash: Faster Speculative Decoding for Vision-Language Models

ทีมวิจัยจาก National University of Singapore นำเสนอ MMFlash เทคนิค speculative decoding สำหรับโมเดล Vision-Language ซึ่งใช้ drafter ขนาดเล็กเสนอ token ล่วงหน้าให้โมเดลหลักตรวจพร้อมกัน งานนี้ชี้ว่า drafter แบบ diffusion อย่าง DFlash ถูกศึกษาเฉพาะงานข้อความ ทีมจึงวัดว่าแต่ละ token พึ่งพาภาพมากเพียงใดด้วย KL divergence ระหว่างการทำนายแบบมีและไม่มีภาพ พบว่าอัตราการยอมรับ token ลดจาก 46% ในกลุ่มที่พึ่งพาภาพน้อยที่สุดเหลือ 22% ในกลุ่มที่พึ่งพาภาพมากที่สุด แม้ผ่านการฝึกแบบ multimodal แล้วก็ตาม MMFlash จึงเพิ่มน้ำหนักการเรียนรู้ให้ token ที่พึ่งพาภาพซึ่ง drafter ทำนายได้ไม่ดี และใช้ sparse attention ลดการคำนวณซ้ำซ้อนสำหรับวิดีโอยาว ผลคือเร่งการถอดรหัสแบบไม่สูญเสียคุณภาพได้สูงสุด 3.58 เท่า ดีกว่า EAGLE-3 สูงสุด 195.4% และดีกว่า DFlash สูงสุด 17.1%

Tech impact: ช่วยลดต้นทุนและ latency ของการให้บริการโมเดล multimodal โดยเฉพาะงานวิดีโอยาว ซึ่งเป็นคอขวดสำคัญของการใช้งานจริง

👩‍💻 Developer

  • ทดลอง speculative decoding กับ VLM ใน inference stack เช่น vLLM/SGLang
  • วัด acceptance rate แยกตามประเภท token เพื่อหาจุดปรับปรุง drafter

💼 Business

  • ประเมินการลดต้นทุน GPU สำหรับบริการวิเคราะห์ภาพและวิดีโอ
  • ใช้ผลลัพธ์นี้ต่อรองหรือเลือกผู้ให้บริการ inference ที่รองรับเทคนิคเร่งความเร็ว
