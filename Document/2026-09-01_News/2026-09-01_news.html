Sliding-window beats linear attention
งานวิจัยชี้ Sliding Window Attention ให้ผลดีกว่า Linear Attention โดยไม่ต้องฝึกโมเดลเพิ่ม
งานวิจัย ใหม่ ชี้ ว่า เทคนิค Sliding Window Attention ที่ มี จุด ยึด หรือ sink ทำงาน ได้ ดี เท่ากับ หรือ ดี กว่า โมเดล Linear Attention ที่ ผ่าน การ ฝึก เพิ่มเติม โดย ไม่ต้อง ผ่าน การ ฝึก เพิ่มเติม ใด ๆ เลย งานวิจัย นี้ ตอบโจทย์ ปัญหา สำคัญ ของ โมเดล ภาษา ขนาด ใหญ่ ที่ ใช้ กลไก Quadratic Attention ซึ่ง กิน หน่วยความจำ และ พลังงาน มากขึ้น เรื่อย ๆ ตาม จำนวน โทเคน ที่ เพิ่มขึ้น ผล การ ทดสอบ บน งาน ให้ เหตุผล บริบท ยาว อย่าง Needle-in-a-Haystack และ BABILong พบ ว่า Sliding Window Attention ทำ คะแนน ได้ สูง กว่า Linear Attention ถึง สอง ถึง สิบ เท่า นักวิจัย แนะนำ ให้ นักพัฒนา ที่ ต้องการ ลด ต้นทุน หน่วยความจำ ระหว่าง การ ใช้งาน โมเดล เปลี่ยน มา ใช้ Sliding Window Attention แทน การ นำ โมเดล ไป ฝึก เพิ่มเติม ด้วย Linear Attention เพราะ ให้ ผลลัพธ์ ที่ เชื่อถือ ได้ กว่า และ ต้นทุน ต่ำ กว่า มาก

บทความ จาก VentureBeat ชี้ ว่า บทบาท ของ วิศวกร ซอฟต์แวร์ กำลัง เปลี่ยนไป จาก การ เขียน โค้ด ด้วย ตนเอง สู่ การ ออกแบบ ขอบเขต และ กลไก ป้อนกลับ ที่ ควบคุม ไม่ให้ AI agent ทำงาน ผิดพลาด เนื่องจาก เครื่องมือ อย่าง Claude Code และ Cursor ทำให้ การ เขียน โค้ด เบื้องต้น ไม่ใช่ คอขวด อีก ต่อไป บทความ เปรียบเทียบ agent กับ เครื่องยนต์ ที่ ต้องการ ทิศทาง ชัดเจน และ อาจ สะสม ความ สับสน หรือ Operational Entropy หาก ขาด การ ป้อนกลับ ที่ แม่นยำ เช่น การ ทดสอบ ที่ ล้มเหลว หรือ สัญญา ข้อมูล ที่ ชัดเจน ระบบ องค์กร ขนาด ใหญ่ มี ความ ซับซ้อน คล้าย ปัญหา สาม วัตถุ ทาง ฟิสิกส์ ที่ การ เปลี่ยนแปลง จุด หนึ่ง ส่งผล กระทบ ไป ทั่ว ระบบ ทำให้ agent อาจ เขียน โค้ด ที่ ผ่าน การ ทดสอบ แต่ ให้ ผล ลัพธ์ ที่ ผิด ทาง ธุรกิจ ได้ วิศวกร จึง ต้อง สร้าง สัญญา ข้อมูล ชั้น ความหมาย ที่ ชัดเจน และ ระบบ ที่ ตรวจสอบ ได้ เพื่อ ให้ agent ทำงาน ได้ อย่าง น่าเชื่อถือ

แอปเปิล ยื่น หลักฐาน ใหม่ ต่อ ศาล ใน คดี ฟ้องร้อง OpenAI กรณี ขโมย ความลับ ทางการค้า โดย กล่าวหา ว่า อดีต พนักงาน แอปเปิล ชื่อ Chang Liu ซึ่ง ปัจจุบัน ทำงาน ให้ OpenAI นำ แผนผัง วงจร ที่ เป็น ความลับ ของ แอปเปิล ไป ใช้ ใน งาน ที่ OpenAI พร้อม กล่าวหา ว่า Liu ได้รับ ความช่วยเหลือ จาก เพื่อนร่วมงาน ที่ OpenAI ใน การ ทำลาย หลักฐาน หลังจาก รู้ตัว ว่า กำลัง ถูก สอบสวน หลักฐาน ใหม่ นี้ มาจาก แล็ปท็อป ทำงาน เก่า ของ Liu ที่ ทนายความ ส่งมอบ ให้ สอบสวน เมื่อ เดือน ที่ผ่านมา OpenAI ออก มา ปฏิเสธ ข้อกล่าวหา โดย ระบุ ว่า Liu เข้าถึง ไฟล์ หลังจาก ออกจาก งาน เพื่อ ช่วยเหลือ อดีต เพื่อนร่วมงาน เท่านั้น แต่ แอปเปิล ยืนยัน ว่า Liu ใช้ ช่องโหว่ การ ยืนยัน ตัวตน ที่ ไม่เคย ถูก ค้นพบ มาก่อน แอปเปิล กำลัง ขอ คำสั่ง ศาล ชั่วคราว ห้าม OpenAI พัฒนา ฮาร์ดแวร์ จาก เทคโนโลยี ของ แอปเปิล พร้อม เปิดเผย ว่า มี อดีต พนักงาน แอปเปิล กว่า สี่ ร้อย คน ทำงาน ที่ OpenAI ใน ปัจจุบัน
