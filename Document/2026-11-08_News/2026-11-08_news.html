VFlash จาก NVIDIA เร่งการวางแผนเชิงภาพของหุ่นยนต์เร็วขึ้น 25 เท่า

Hugging Face Daily Papers · Research · MEDIUM · BREAKTHROUGH · 2026-11-07T09:00

ทีมวิจัย NVIDIA นำโดย Yu-Cheng Chou ร่วมกับนักวิจัยอย่าง Linxi Fan, Jan Kautz และ Alan Yuille เผยแพร่งานวิจัย VFlash ซึ่งขึ้นอันดับหนึ่งของ Hugging Face Daily Papers เมื่อ 7 พ.ย. 2569 ด้วยคะแนนโหวต 100 งานนี้แก้ปัญหาที่ vision-language model แบบ autoregressive ต้องสร้างพิกัดของจุด กรอบวัตถุ และเส้นทางการเคลื่อนที่ทีละ token ทำให้การวางแผนเชิงภาพสำหรับหุ่นยนต์และรถยนต์อัตโนมัติช้าและมีต้นทุนสูง VFlash ใช้เทคนิค Flash Primitive Decoding ที่อาศัยโครงสร้างที่รู้อยู่แล้วของ primitive เพื่อทำนายพิกัดทั้งหมดพร้อมกัน ผ่าน drafter ขนาดเล็กที่สร้าง primitive ทั้งชิ้นได้ใน forward pass เดียว รองรับทั้งกรอบวัตถุขนาดเล็กและเส้นทางยาวที่ความยาวไม่แน่นอน และยอมรับผลลัพธ์ที่ถูกต้องเชิงโครงสร้างแม้ไม่ตรงกับลำดับ token เดิม ผลลัพธ์คือความคลาดเคลื่อนต่ำกว่าการถอดรหัสแบบเดิมในงานเส้นทางหุ่นยนต์ 2D และ 3D สร้างผลได้เร็วขึ้นราว 25 เท่าในการพยากรณ์การเคลื่อนที่ของจุด 3D และ world action model ที่ใช้แผนจาก VFlash มีอัตราสำเร็จเฉลี่ย 70.2% บน MolmoSpaces สี่ชุด เทียบกับ 62.6% ของ baseline นับเป็นก้าวสำคัญของ Physical AI ที่ต้องตัดสินใจแบบเรียลไทม์

Impact: การถอดรหัส primitive แบบขนานช่วยลด latency ของ VLM ในหุ่นยนต์ลงมาก และเพิ่มความสำเร็จของงานจับวางได้ 7.6 จุด ซึ่งสำคัญต่อการใช้งานจริงบนอุปกรณ์ edge

  • ติดตามโค้ดและโมเดลของ VFlash สำหรับระบบ robot planning
Business
  • ประเมินว่าความเร็วที่เพิ่มขึ้นช่วยลดต้นทุนฮาร์ดแวร์หุ่นยนต์ได้เท่าใด
  • จับตา NVIDIA ในฐานะผู้นำ stack ของ Physical AI

WeLM-Image โมเดลสร้างภาพแบบรวมของ WeChat ขึ้นอันดับหนึ่งโอเพนซอร์ส สร้างภาพใน 4.98 วินาที

Hugging Face Daily Papers · Research · LOW · 2026-11-07T09:00

ทีมนักวิจัย 16 คนที่พัฒนาโมเดลสำหรับแอปพลิเคชันของ WeChat เผยแพร่ WeLM-Image โมเดลพื้นฐานด้านภาพแบบรวมศูนย์ ซึ่งติดอันดับ Hugging Face Daily Papers เมื่อ 7 พ.ย. 2569 โมเดลนี้รองรับการสร้างภาพจากข้อความ การแก้ไขภาพตามคำสั่ง และการสังเคราะห์จากภาพอ้างอิงหลายภาพ โดยประมวลผลข้อความ ภาพอ้างอิง และ latent เป้าหมายเป็นลำดับเดียวกัน สถาปัตยกรรมเป็น Mixture-of-Transformers ที่ใช้ attention ร่วมกันแต่แยกพารามิเตอร์ด้านความเข้าใจกับการสร้างภาพ เพื่อลดการรบกวนกันระหว่างการปรับจูน เสริมด้วยโมดูล Mixture-of-Experts มีพารามิเตอร์รวม 31.7B แต่ใช้งานจริงราว 5.4B ต่อ latent token ฝึกแบบก้าวหน้าจนถึงความละเอียดเนทีฟ 1.5K ใช้รางวัลแบบ rubric และ checklist แล้วรวมความสามารถด้วย on-policy distillation ผู้วิจัยรายงานว่ารุ่น 1536 ได้อันดับหนึ่งในกลุ่มโมเดลโอเพนซอร์สที่ประเมินบน PRISM-Bench, Qwen-Image-Bench และ UnicBench ส่วนรุ่น WeLM-Image-Turbo สร้างภาพ 1024×1024 ได้ใน 4.98 วินาทีบน GPU NVIDIA H20 เพียงตัวเดียวด้วย 8 step แสดงว่าโมเดลภาพคุณภาพสูงสามารถให้บริการผู้ใช้จำนวนมหาศาลบน GPU เดียวได้อย่างคุ้มค่า

Impact: สถาปัตยกรรม MoT+MoE ที่ active เพียง 5.4B และรันบน GPU เดียวชี้ทิศทางของโมเดลภาพที่คุ้มค่าสำหรับบริการผู้บริโภคขนาดใหญ่ และเพิ่มการแข่งขันจากฝั่งจีน

Developer
  • ศึกษาแนวคิด Mixture-of-Transformers แยกพารามิเตอร์ understanding/generation
  • ทดสอบการใช้ few-step distillation (MeanFlow) เพื่อลดเวลาสร้างภาพ
Business
  • ประเมินต้นทุนต่อภาพของโมเดลที่รันบน GPU เดียวสำหรับงานการตลาด
  • จับตาโมเดลภาพจากจีนที่อาจถูกเปิดให้ใช้เชิงพาณิชย์

Harness-S ฝึก LLM agent ด้วย harness พี่น้องช่วยกู้ความล้มเหลว เพิ่มความสามารถทั่วไป

Hugging Face Daily Papers · Research · LOW · 2026-11-07T09:00

นักวิจัยนำโดย Kangning Zhang และ Weinan Zhang เผยแพร่งานวิจัย Harness-S ซึ่งติดอันดับ Hugging Face Daily Papers เมื่อ 7 พ.ย. 2569 ด้วยคะแนนโหวต 63 งานนี้ศึกษาการพัฒนา harness หรือระบบที่ห่อหุ้มการทำงานของ LLM agent และพบสามรูปแบบสำคัญ คือ locality ที่แต่ละเวอร์ชันแก้ข้อผิดพลาดต่างกัน complementarity ที่เสริมกันได้ และ nonstationarity ที่ประโยชน์ของแต่ละเวอร์ชันเปลี่ยนไปตามการเรียนรู้ของ policy แทนที่จะค้นหา harness ที่ดีที่สุดเพียงหนึ่งเดียว Harness-S สร้าง Sibling Harness Pool ที่แต่ละตัวมุ่งซ่อมคนละทิศทาง และเรียกใช้เฉพาะเมื่อทุกความพยายามภายใต้ harness หลักล้มเหลว จากนั้นนำ rollout ที่สำเร็จมาแทนกลุ่มที่ล้มเหลวในการฝึก reinforcement learning พร้อม Adaptive Harness Router ที่เลือก Top-k ด้วยการโหวตจาก LLM หลายตัว และปรับหลักฐานตามพัฒนาการของ policy ผลทดสอบบน AppWorld, SWE-Gym และ DBBench พบว่า policy ที่ฝึกแล้วทำงานได้ดีกว่าการฝึก policy อย่างเดียวอย่างชัดเจน แม้รันบน harness เดิม แสดงว่าพฤติกรรมที่ harness ช่วยกระตุ้นถูกถ่ายทอดเข้าสู่ตัวโมเดลได้จริง ซึ่งเป็นแนวทางที่มีประโยชน์ต่อการฝึก coding agent และ agent ทั่วไป

Impact: แนวคิดใช้ harness หลายแบบช่วยกู้ rollout ที่ล้มเหลวทำให้การฝึก agent ด้วย RL มีสัญญาณเรียนรู้มากขึ้น โดยไม่ต้องเปลี่ยนระบบที่ใช้งานจริง

Developer

  • นำ trajectory ที่กู้ได้มาใช้เป็นข้อมูล fine-tune หรือ RL
Business
  • ประเมินว่าการลงทุนปรับ harness ให้ผลคุ้มกว่าการเปลี่ยนโมเดลหรือไม่
  • ติดตามเทคนิคฝึก agent ที่ลดต้นทุนการพัฒนา coding agent ภายในองค์กร

SLA ยกระดับโมเดล VLA ให้เข้าใจพื้นที่ 3D ตั้งแต่ขั้น pre-training

Hugging Face Daily Papers · Research · LOW · 2026-11-07T09:00

ทีมวิจัยนำโดย Fuhao Li และ Haoang Li จาก HKUST (Guangzhou) เผยแพร่ SLA หรือ Spatial-Language-Action model ซึ่งติดอันดับสามของ Hugging Face Daily Papers เมื่อ 7 พ.ย. 2569 ด้วยคะแนนโหวต 81 งานนี้ชี้ว่าโมเดล vision-language-action (VLA) ปัจจุบันส่วนใหญ่สืบทอดฟีเจอร์ภาพจากการ pre-train แบบ 2D และเพิ่มการกำกับเชิงพื้นที่เฉพาะตอน fine-tune ทำให้ควบคุมแขนกลในโลก 3D ได้ไม่แม่นยำพอ SLA จึงเพิ่มการจัดแนวเชิงพื้นที่ตั้งแต่ขั้น continual pre-training โดยเริ่มจาก policy pi05 แล้วฝึกการทำนาย action ร่วมกับการจัดแนว embedding ภาพกับ representation จากโมเดลรับรู้ 3D ที่ถูกแช่แข็งไว้ ใช้ feature-dependent gates รวม embedding จากหลายเลเยอร์ ใช้ข้อมูล RGB พร้อม depth และค่าคาลิเบรตกล้องที่มีเพียงบางส่วน และใช้ probabilistic state dropout เพื่อลดการ overfit กับเส้นทางสาธิต ข้อมูลฝึกรวบรวมจากชุดข้อมูลหุ่นยนต์หลายรูปแบบ หลายงาน และหลายฉาก ที่สำคัญคือทุกองค์ประกอบเสริมใช้เฉพาะช่วงฝึก จึงนำน้ำหนักไปใช้ได้ทันทีโดยไม่ต้องเปลี่ยนสถาปัตยกรรม inference ทำให้นักพัฒนาหุ่นยนต์ยกระดับความแม่นยำเชิงพื้นที่ได้โดยไม่เพิ่มต้นทุนการรันระบบ

Impact: การฝัง spatial supervision ตั้งแต่ pre-training โดยไม่เปลี่ยน inference ช่วยให้ทีมหุ่นยนต์อัปเกรดโมเดล VLA ได้ง่าย ลดช่องว่างระหว่างความเข้าใจภาษาและการควบคุม 3D

  • ใช้ state dropout ลด overfitting กับ demonstration ในชุดข้อมูลหุ่นยนต์
Business
  • ติดตามโมเดล VLA โอเพนซอร์สสำหรับงาน manipulation ในโรงงาน
  • ประเมินการรวมชุดข้อมูลหุ่นยนต์หลายแหล่งเพื่อลดต้นทุนเก็บข้อมูล

OpenAI จับมือ Hacktron ใช้ AI agent ล่าช่องโหว่ในระบบของตัวเอง

OpenAI (via DEV Community digest) · International · MEDIUM · 2026-11-07T23:00

OpenAI ประกาศเมื่อ 7 พ.ย. 2569 ว่าร่วมมือกับ Hacktron บริษัทความปลอดภัยที่พัฒนา AI agent สำหรับ code review, penetration testing และ red teaming เพื่อค้นหาช่องโหว่ในระบบของ OpenAI เอง โดยเน้นจุดที่บริการของ OpenAI เชื่อมต่อกับแพลตฟอร์มภายนอก ทีมร่วมของทั้งสองฝ่ายจะกำหนดพื้นที่ทดสอบที่มีความสำคัญสูงสุด และ Hacktron จะได้สิทธิ์เข้าถึงโมเดล frontier ที่กว้างขึ้นผ่านโปรแกรม Daybreak Red ซึ่งเปิดให้ใช้โมเดลที่ฝึกมาเฉพาะด้านไซเบอร์ภายใต้การกำกับดูแลใกล้ชิด OpenAI ระบุว่ากำลังใช้ความเร่งด่วนแบบเดียวกันในการค้นหาและแก้ไขช่องโหว่ในระบบของตนเอง ความเคลื่อนไหวนี้เกิดขึ้นหลังจาก OpenAI เปิดตัว GPT-6 Cyber เมื่อ 5 พ.ย. ซึ่งบริษัทอ้างว่าค้นพบช่องโหว่ระดับร้ายแรงใน Firefox 81 รายการ และสร้าง exploit ของ Linux kernel ที่ใช้งานได้ 948 รายการ ด้วยเครดิต API ราว 1.2 ล้านดอลลาร์ แม้ตัวเลขเหล่านี้ยังไม่ผ่านการตรวจสอบอิสระ แต่สะท้อนว่าห้องแล็บ AI กำลังใช้ AI agent ตรวจสอบความปลอดภัยของตัวเองก่อนที่ผู้โจมตีจะใช้เครื่องมือแบบเดียวกัน

Impact: การที่ OpenAI ใช้ AI red team กับระบบตัวเองเป็นสัญญาณว่า AI-driven pentest จะกลายเป็นมาตรฐานใหม่ องค์กรที่เชื่อมต่อ API ของ OpenAI ควรคาดการณ์การเปลี่ยนแปลงด้านความปลอดภัยของ integration
