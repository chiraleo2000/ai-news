Simon Willison นักพัฒนาและบล็อกเกอร์ AI ชื่อดัง รีวิวโมเดล open weights ตัวใหม่จาก Qwen ชื่อ Qwen3.8-Flash-Next ซึ่งเป็นโมเดล multimodal แบบ mixture-of-experts (MoE) ที่บริษัทระบุว่าเป็นตัวอย่างล่วงหน้าของสถาปัตยกรรมที่จะใช้ใน Qwen4 โมเดลนี้มีขนาดใหญ่ถึง 125B พารามิเตอร์ แต่ทำงาน active เพียง 6B พารามิเตอร์ต่อครั้ง ทำให้ได้ประสิทธิภาพความเร็วที่ดีขึ้นอย่างมีนัยสำคัญ Willison ทดลองรันบนเครื่อง Nvidia DGX Spark โดยใช้โมเดล quantized จาก Unsloth ทั้งเวอร์ชัน 72.5GB (UD-IQ1_S) และ 78.9GB (UD-Q2_K_XL) ผ่านการทดสอบ benchmark แบบไม่เป็นทางการยอดฮิตในวงการคือการให้โมเดลวาดภาพ pelican riding a bicycle ซึ่งเป็นวิธีที่เขาใช้เปรียบเทียบคุณภาพโมเดลภาษาต่าง ๆ มาอย่างต่อเนื่อง สะท้อนความเคลื่อนไหวต่อเนื่องของค่าย AI จีนในการปล่อยโมเดล open weights คุณภาพสูงออกมาแข่งขันกับค่ายตะวันตก

Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses
วิวัฒนาการหน่วยความจำแบบ Experiential-Working สำหรับ AI Agent ที่ทำงานระยะยาว
ทีมวิจัยจาก Gen-Verse นำเสนอ Recuris สถาปัตยกรรมหน่วยความจำแบบ Experiential-Working Memory สำหรับ agent ที่ต้องทำงานระยะยาว (long-horizon) เพื่อแก้ปัญหา recursive self-improvement (RSI) ที่ประวัติการทำงานสะสมมากขึ้นจนบดบังสถานะของงานและทำให้เลือกใช้ skill ผิด ระบบใช้ Working Memory ติดตามความคืบหน้าและเลือก skill จาก Experiential Memory โดยอิงความต้องการปัจจุบันแทนประวัติทั้งหมด พร้อมมี Meta-Agent ที่แปลงหลักฐานการทำงานเป็นการอัปเดต Skill Memory แบบมีการตรวจสอบ (validation-gated) ผลทดสอบบน 4 long-horizon benchmark และโมเดล 10 ตัว พบว่า Recuris ช่วยเพิ่มอัตราความสำเร็จของงานใน 35 จาก 37 คู่โมเดล-benchmark เช่น เพิ่ม +17.8 คะแนนให้ GPT-5.6 Sol และ +15.6 คะแนนให้ Claude Opus 5 บน tau-bench จนแตะ 87.9% และลด failure ในงานยาวได้ถึง 80% งานนี้ชี้ให้เห็นว่าหน่วยความจำที่วิวัฒนาการได้เองอาจเป็นรากฐานสำคัญของ RSI ในอนาคต

Meta^n: การพัฒนาตัวเองแบบ Recursive ผ่านความลึกที่เกิดขึ้นเอง
ทีมวิจัยจาก University of Minnesota เสนอ Meta^n แนวทางใหม่สำหรับ recursive self-improvement (RSI) ของ LLM agent ที่แก้ปัญหาความลึกของ meta-level ซึ่งเดิมถูกจำกัดไว้ที่ประมาณ 2 ชั้นเพราะระบบต้องรักษาส่วนหนึ่งของกลไกแก้ไขตัวเองให้คงที่เพื่อความเสถียร วิธีการนี้ตรึงตัวดำเนินการ meta-operation (Omega) ให้คงที่ แต่ให้มัน recurse บน input ของตัวเองซ้ำไปเรื่อยๆ โดยอ่าน trace ของ solver stack ชั้นล่างพร้อมโค้ดที่สร้างมันขึ้นมา แล้วเขียนชั้นถัดไปเป็นทั้ง pre-process เชิงกลยุทธ์และคลัง helper ที่เรียกใช้ได้ ความลึกของระบบถูกกำหนดโดยการลู่เข้า (convergence) ไม่ใช่ค่าคงที่ที่ตั้งไว้ล่วงหน้า ผลทดลองบน 2 backbone พบว่า Meta^n ชนะ agent ที่ self-improve แบบเดิมในทุก 8 กลุ่ม benchmark โดยเฉพาะบน ARC-AGI-2 ที่ออกแบบมาต้านการจดจำ skill ซึ่ง Meta^n เป็นระบบเดียวที่ทำคะแนนได้สูงกว่าศูนย์ งานนี้ชี้ให้เห็นศักยภาพของ RSI ที่ลึกและปรับตัวได้มากกว่าที่เคยทำได้

Effective Learning Rate Governs Loss Dynamics in Language Model Pretraining
Effective Learning Rate ตัวแปรที่ควบคุม Loss Dynamics ในการ Pretrain Language Model
ทีมวิจัยค้นพบปรากฏการณ์ที่เรียกว่า ELR collapse ในการ pretrain language model โดยพบว่า learning rate (LR) และ parameter norm ควบคุม dynamics ของ loss เป็นหลักผ่านอัตราส่วนของทั้งสอง ที่เรียกว่า effective learning rate (ELR) เมื่อ ELR ถูกจับคู่ให้เท่ากันระหว่างการรัน loss trajectory จะทับกันตลอดการฝึกแม้ LR และ parameter norm จะต่างกันมาก ผลการทดลองในหลาย optimizer สถาปัตยกรรม dataset และขนาดโมเดล พบว่าค่า error จากการทับกันของ loss อยู่ที่ระดับไม่กี่ x10^-3 ซึ่งต่ำกว่าความแปรผันระหว่าง seed การทดลองแบบควบคุมยังชี้ว่า weight decay และเทคนิค Hyperball ส่งผลต่อ loss dynamics ผ่าน ELR schedule ที่มันสร้างขึ้นเป็นหลัก การแทนที่ LR ด้วย ELR ทำให้ functional scaling law (FSL) ที่ fit ไว้สามารถถ่ายโอนข้ามวิธี norm-control ต่างๆ ได้ งานนี้ชี้ว่า ELR อาจเป็นตัวแปรร่วมที่เชื่อมโยง LR scheduling, norm control และ loss dynamics เข้าด้วยกัน

Anthropic ได้ลงนามข้อตกลงมูลค่าประมาณ 45,000 ล้านดอลลาร์สหรัฐ กับ Nscale บริษัทโครงสร้างพื้นฐาน AI สัญชาติอังกฤษที่ก่อตั้งเมื่อปี 2024 เพื่อเช่ากำลังประมวลผล AI โดยจะใช้ชิป Nvidia รุ่นใหม่ล่าสุดอย่าง Vera Rubin ซึ่งรวมชิป 6 ตัวทำงานร่วมกัน กำลังประมวลผลนี้จะเริ่มขับเคลื่อนบริการของ Anthropic ตั้งแต่ปลายปี 2027 เป็นต้นไป ข้อตกลงนี้มีระยะเวลา 6 ปี และดึงพลังงานคอมพิวท์จากศูนย์ข้อมูลหลักของ Nscale ในรัฐเวสต์เวอร์จิเนีย นับเป็นดีลล่าสุดในสตรีค compute-gobbling ของ Anthropic หลังจากเพิ่งเซ็นดีล 10,000 ล้านดอลลาร์กับ Volta และ 5,000 ล้านดอลลาร์กับ AMD ก่อนหน้านี้ในปีเดียวกัน รวมถึงดีลกับ SpaceX, Amazon และ Google/Broadcom เพื่อขยาย GPU และ TPU capacity ให้เพียงพอต่อการแข่งขันกับ OpenAI และ Google ในสมรภูมิ AI ที่ต้องการพลังประมวลผลมหาศาลอย่างต่อเนื่อง

Bringing ChatGPT for Teachers to more U.S. school districts
OpenAI ขยาย ChatGPT for Teachers สู่เขตการศึกษาสหรัฐฯ เพิ่มอีกกว่า 100,000 ครูและบุคลากร
OpenAI ประกาศขยายโครงการ ChatGPT for Teachers ไปยังเขตการศึกษาเพิ่มอีก 55 แห่งใน 20 รัฐของสหรัฐฯ ครอบคลุมครูและบุคลากรเพิ่มอีกกว่า 100,000 คน จากเดิมที่เริ่มโครงการในปี 2025 กับครูเกือบ 150,000 คน ทำให้ปัจจุบัน OpenAI ทำงานร่วมกับองค์กรการศึกษาระดับ K-12 มากกว่า 100 แห่งใน 30 รัฐ ให้สิทธิ์ใช้งานฟรีและฝึกอบรมแก่บุคลากรกว่า 300,000 คน พร้อมประกาศข้อตกลงความเป็นส่วนตัวข้อมูล National Data Privacy Agreement ครอบคลุม 16 รัฐ ซึ่งเป็นครั้งแรกของอุตสาหกรรมที่ให้กรอบมาตรฐานเดียวสำหรับประเมินความปลอดภัยข้อมูลนักเรียน ChatGPT for Teachers จะยังคงให้ใช้งานฟรีสำหรับครู K-12 ที่ผ่านการยืนยันตัวตนจนถึงเดือนมิถุนายน 2028 โดยข้อมูลจากการวิเคราะห์พบว่าครูส่งข้อความเกี่ยวกับงานประหยัดเวลากว่า 1.9 ล้านข้อความ ตั้งแต่มกราคมถึงกรกฎาคม 2026
