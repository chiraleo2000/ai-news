Elucidating the Design Space of LM Data Attribution

งานวิจัยจาก MIT และพันธมิตร โดย Antonio Torralba และ David Bau ศึกษาการระบุว่าพฤติกรรมของโมเดลภาษามาจากเอกสารฝึกชิ้นใด หรือ data attribution ผู้เขียนชี้ว่าเกณฑ์วัดเดิมเปลี่ยนคุณสมบัติของชุดข้อมูลหลายอย่างพร้อมกัน จึงอธิบายไม่ได้ว่าวิธีใดล้มเหลวเพราะอะไร จึงสร้าง Controlled Attribution Benchmark หรือ CATT โดยปรับจูน LLM ด้วยข้อเท็จจริงที่แต่งขึ้นเพื่อให้รู้เอกสารต้นทางที่แท้จริง แล้วเปลี่ยนทีละตัวแปร พบว่าเนื้อหาซ้ำและตัวหลอกเชิงคำศัพท์ทำให้ประสิทธิภาพลดลง ผู้เขียนพบอีกว่าหลักฐานเชิงสาเหตุกระจุกอยู่ในไม่กี่โทเคน แต่วิธีมาตรฐานเฉลี่ยทั้งเอกสารจนเจือจาง และการใช้เกรเดียนต์ negative log-odds แทน cross-entropy ช่วยแยกโทเคนสำคัญได้ดีกว่า การรวมคะแนนเฉพาะโทเคนบนสุดเพิ่ม ground-truth recall 35 ถึง 72 จุดเปอร์เซ็นต์ และดีขึ้นสูงสุด 4.9 เท่าบน FTRACE-TREX

Impact: เครื่องมือตรวจสอบว่าโมเดลเรียนจากข้อมูลใดช่วยงานตรวจสอบลิขสิทธิ์ ความเป็นส่วนตัว และการดีบักพฤติกรรมโมเดล ผลวิจัยนี้ทำให้วิธีวัดผลน่าเชื่อถือขึ้น

Claude API raises maximum request size from 32 MB to 128 MB

Anthropic ประกาศผ่านบัญชี ClaudeDevs ว่าได้เพิ่มขนาดคำขอสูงสุดของ Claude API ทั้ง Messages และ Token Counting จากเดิม 32 MB เป็น 128 MB หรือเพิ่มขึ้นสี่เท่า ทำให้นักพัฒนาส่งข้อมูลต่อคำขอได้มากขึ้น เช่น เอกสาร PDF ขนาดใหญ่ ภาพหลายภาพ หรือไฟล์แนบจำนวนมากในคำขอเดียว โดยไม่ต้องแบ่งไฟล์ออกเป็นหลายคำขอ ซึ่งช่วยลดความซับซ้อนของโค้ดฝั่งแอปพลิเคชัน อย่างไรก็ตาม ข้อจำกัดของหน้าต่างบริบทยังคงมีผลแยกต่างหาก หมายความว่าแม้ขนาดคำขอจะใหญ่ขึ้น จำนวนโทเคนที่โมเดลรับได้ก็ยังเป็นเพดานเดิม นักพัฒนาจึงควรใช้ Token Counting ตรวจสอบก่อนส่ง การปรับนี้เป็นประโยชน์กับงานวิเคราะห์เอกสารขนาดใหญ่ งานประมวลผลภาพและไฟล์หลายชิ้น และเวิร์กโฟลว์ที่เอเจนต์ต้องส่งบริบทจำนวนมากกลับเข้าโมเดลในแต่ละรอบ

Impact: เพิ่มความยืดหยุ่นในการส่งเอกสารและสื่อขนาดใหญ่ผ่าน API โดยตรง ลดงานแบ่งไฟล์ แต่ต้องดูเพดานหน้าต่างบริบทควบคู่กัน
