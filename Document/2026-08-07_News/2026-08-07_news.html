Control-Plane Placement Shapes Forgetting: An Architectural Study of Agent Memory Across Thirteen System Configurations

ForgetEval เผยให้เห็นว่าตำแหน่งของ LLM ใน agent memory pipeline กำหนดว่า forgetting failure modes ใดที่สามารถ recover ได้ โดยเปรียบเทียบ 13 system configurations บน 385 adversarial test cases พบว่า mutation-time hooks ทำได้ 91.7-93.2% overall accuracy ในขณะที่ deterministic-only approaches ทำได้เกือบ 0% สำหรับ canonicalization และ intent-aware deletion การจัดวาง LLM ที่ inscribe-time บรรลุ 100% canonicalization แต่ช่วยไม่ได้เลยสำหรับ intent-aware deletion ในขณะที่ mutation-time hook แก้ได้ 78-85% สำหรับ intent-aware deletion ด้วยต้นทุนเพียง $0.17 ต่อ 385 cases insight หลักคือ production agent failures ส่วนใหญ่เป็น forgetting failures แต่ benchmark ที่มีอยู่วัดแค่ recall เท่านั้น ForgetEval (1000-case templated + 385 adversarial) เผยแพร่ภายใต้ MIT license
