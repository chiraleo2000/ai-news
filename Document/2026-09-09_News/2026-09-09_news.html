Google DeepMind เปิดตัว AlphaGenome Atlas ฐานข้อมูลที่รวบรวมผลการทำนายผลกระทบระดับโมเลกุลของการเปลี่ยนแปลงดีเอ็นเอแบบจุดเดียว (Single-nucleotide Variant) ครบทุกตำแหน่งที่เป็นไปได้ในจีโนมมนุษย์ ราว 9 พันล้านตำแหน่ง ขนาดข้อมูลรวม 1 เพตะไบต์ ใหญ่กว่า AlphaFold Database ถึง 30 เท่า พร้อมนำเสนอคะแนน AlphaGenome Variant Impact หรือ AVI ที่รวมผลจาก AlphaGenome และ AlphaMissense เข้าด้วยกันเพื่อจัดอันดับผลกระทบของยีนได้ทั้งในส่วนเข้ารหัสโปรตีนและส่วนที่ไม่เข้ารหัสซึ่งคิดเป็น 98% ของจีโนม เปิดให้ใช้งานฟรีผ่านเว็บพอร์ทัลและ API สำหรับงานวิจัยเชิงวิชาการ ทีมพันธมิตรภายนอกที่ทดลองใช้ก่อนเปิดตัวพบผลลัพธ์สำคัญ เช่น การค้นพบยีน DNM1 ที่เกี่ยวข้องกับโรคลมชักในทารกจากทีม Broad Institute และการค้นพบความสัมพันธ์เชิงพันธุกรรมเพิ่มขึ้น 22% จากข้อมูลจีโนม UK Biobank กว่า 54,000 ราย

NVIDIA ประกาศเปิดตัว CUDA Rust ผลักดันให้ Rust กลายเป็นภาษาชั้นหนึ่งสำหรับเขียน GPU Kernel ผ่านโปรเจกต์โอเพนซอร์สสองตัวคือ cuda-oxide สำหรับโมเดล SIMT แบบดั้งเดิม และ cutile-rs สำหรับโมเดล Tile รุ่นใหม่ ทั้งสองคอมไพล์ Rust Kernel ได้โดยตรงและใช้กฎ Ownership ของ Rust ตรวจจับบั๊กการอ้างอิงหน่วยความจำซ้ำซ้อน (Aliasing) ได้ตั้งแต่ขั้นตอนคอมไพล์ก่อนรันจริง cutile-rs เผยแพร่บน crates.io รองรับ Rust เสถียรตั้งแต่เวอร์ชัน 1.89 และถูกนำไปใช้แล้วใน Grout ของ Hugging Face และ mistral.rs ขณะที่ cuda-oxide ยังอยู่ในระยะอัลฟาช่วงต้น ทั้งสองโปรเจกต์สะท้อนแนวโน้มที่ชั้นระบบของ AI ตั้งแต่ Inference Engine ไปจนถึงไดรเวอร์และ Agent Runtime หันมาใช้ Rust มากขึ้นเรื่อย ๆ
