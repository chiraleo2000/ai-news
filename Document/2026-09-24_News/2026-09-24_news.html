Diffusion Large Language Model เป็นแนวทาง generate ข้อความแบบ non-autoregressive ที่เริ่มได้รับความสนใจเป็นทางเลือกของโมเดล autoregressive ทั่วไป แต่การ deploy จริงยังติดปัญหาด้าน inference ที่ไม่มีประสิทธิภาพ เพราะกลไก Key-Value caching และ parallel decoding เดิมยังไม่เหมาะสม งานนี้เสนอ Flash-dLLM เฟรมเวิร์กแบบ training-free ที่แก้ปัญหาโดยระบุว่า GPU memory I/O เป็นคอขวดหลัก จึงออกแบบ fused kernel แบบ IO-aware เพื่อลดการอ่านเขียนหน่วยความจำที่ซ้ำซ้อน พร้อมใช้กลยุทธ์ draft-and-verify decoding ที่ให้โมเดลตัวเดียวทำหน้าที่ทั้ง draft และ verify โดยไม่ต้องพึ่ง auxiliary model แยกต่างหาก ผลทดสอบบนงาน mathematical reasoning และ code generation แสดงให้เห็นว่า Flash-dLLM เร็วกว่า baseline ที่แข็งแกร่งที่สุดอย่าง Elastic-Cache ถึง 5.1 เท่าและ 11.0 เท่าตามลำดับ โดยทีมงานได้เปิด code ผ่าน GitHub ให้นักพัฒนานำไปทดลองต่อได้ทันที
