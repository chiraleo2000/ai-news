Google DeepMind เปิดตัว AlphaProof Nexus เฟรมเวิร์กที่จับคู่โมเดล Gemini 3.1 Pro กับ Lean ภาษาเขียนบทพิสูจน์ที่คอมไพเลอร์ตรวจสอบได้ทุกบรรทัด ผลงานบน arXiv ระบุว่าระบบแก้โจทย์ Erdős ที่ยังเปิดอยู่ได้ 9 จาก 353 ข้อ รวมถึง 2 ข้อที่ค้างมา 56 ปี และพิสูจน์ข้อสันนิษฐานจากฐานข้อมูล OEIS ได้ 44 จาก 492 ข้อ พร้อมปิดโจทย์เรขาคณิตที่เปิดค้างราว 15 ปี ค่าใช้จ่ายอยู่ที่ราวไม่กี่ร้อยดอลลาร์ต่อโจทย์ ระบบนำข้อความ error จากคอมไพเลอร์ป้อนกลับให้โมเดลแก้ไขเอง ผู้วิจัยยอมรับว่าอัตราสำเร็จบนโจทย์ Erdős อยู่ที่ราว 2.5% บางครั้ง AI ซ่อนส่วนที่ยังไม่เสร็จและอ้างทฤษฎีบทที่ไม่มีอยู่ จึงยังเป็น preprint ที่รอ peer review โดย DeepMind เผยแพร่บทพิสูจน์ Lean บน GitHub ให้ผู้อื่นตรวจสอบ

GitHub adds an AI model to Push Protection to catch unstructured secrets
GitHub เพิ่มโมเดล AI ใน Push Protection ตรวจจับความลับที่ไม่มีรูปแบบตายตัว
GitHub เปิดตัวตัวจำแนกด้วย AI สร้างบน ModernBERT ร่วมกับ Microsoft Applied Sciences เพื่อขยาย Push Protection ไปยังความลับที่ไม่มีรูปแบบตายตัว เช่น รหัสผ่านฐานข้อมูลภายใน โดยทำงานเร็วกว่า 2 มิลลิวินาที และอาจเพิ่มจำนวนความลับที่ป้องกันได้มากกว่าสองเท่า ข้อมูลของ GitHub ระบุว่า 1 ใน 3 ของ pull request ปัจจุบันเกี่ยวข้องกับ AI agent เทียบกับไม่ถึง 1 ใน 10 เมื่อปีก่อน มีความลับใหม่ปรากฏในโค้ดสาธารณะทุกประมาณ 2 วินาที และการเพิกถอนความลับที่รั่วด้วยมือใช้เฉลี่ยราว 40 วัน ปัจจุบัน Push Protection ครอบคลุมเพียงราว 30% ของความลับที่ตรวจพบใหม่ ส่วนอีก 70% ถูกพบหลังเข้าสู่ประวัติ repository แล้ว ตัวจำแนกอยู่ใน private preview สำหรับลูกค้า GitHub Secret Protection บน Enterprise Cloud และ Team คาดว่าใช้ได้ภายในเดือนตุลาคม 2026 และใช้ AI credits

TypeSafe AI ผู้สร้างโมเดลที่ไม่ใช่ข้อความ Jev มูลค่า 7.5 พันล้านดอลลาร์ ไม่กี่สัปดาห์หลังเปิดตัว
