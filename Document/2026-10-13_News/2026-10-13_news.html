Meta releases its first frontier model, Muse Wonder

Meta Superintelligence Lab เปิดตัวโมเดล Muse Wonder และ Muse Wonder Full เมื่อวันจันทร์ที่ 12 ตุลาคม 2026 ซึ่งเป็น frontier model ตัวแรกของบริษัท โดยใหญ่และเก่งกว่า Muse Spark ที่เน้นความหน่วงต่ำ ทั้งด้านโค้ดดิ้งและงานซับซ้อน ตาม model card ผลทดสอบ benchmark ใกล้เคียงกับ Fable 5.1 และ GPT-6 Astra และทำคะแนนบน MemoryBench สูงกว่า Fable, Opus และ Astra จากความสามารถ active memory ที่จดจำสิ่งสำคัญของผู้ใช้ได้นานเป็นวัน สัปดาห์ และเดือน ราคาผ่าน Meta Model API อยู่ที่ 4 ดอลลาร์ต่อ input 1 ล้าน token และ 20 ดอลลาร์ต่อ output 1 ล้าน token ใกล้เคียง GPT-6 Sol หรือ Opus 5.5 ส่วน Wonder Full ให้เฉพาะสมาชิก Muse Code ไม่เปิดผ่าน API ทั้งสองรุ่นจะขับเคลื่อน Muse agent และฝึกที่ศูนย์ข้อมูล Prometheus ในรัฐโอไฮโอ นับเป็นการกลับเข้าสู่สนามแข่งระดับแนวหน้าของ Meta หลัง Alexandr Wang ปรับโครงสร้างงาน AI เมื่อเดือนสิงหาคม 2025

A Privileged Teacher That Only Scores Cannot Search: Critique-Conditioned On-Policy Self-Distillation for Reasoning

งานวิจัยบน arXiv ชื่อ A Privileged Teacher That Only Scores Cannot Search โดย Mayug Maniparambil, Ayush Rai และคณะ ได้รับคัดเลือกเป็น oral ในเวิร์กชอป FLLMPT ของ NeurIPS 2026 ศึกษา on-policy self-distillation ซึ่งให้เครดิตระดับ token แทนรางวัลแบบเบาบางใน RL ที่ตรวจสอบได้ ผู้เขียนพบว่า KL และ token log-ratio ระบุตำแหน่งข้อผิดพลาดในการให้เหตุผลไม่ได้ เพราะการหาข้อผิดพลาดเป็นปัญหาการค้นหา ซึ่งครูที่ทำได้เพียงให้คะแนนไม่เคยถูกให้ค้นหา วิธีที่เสนอคือ critique-conditioned self-distillation ให้โมเดลเขียนคำวิจารณ์ต่อ rollout ก่อน แล้วครูใช้คำวิจารณ์นั้นให้คะแนน ซึ่งช่วยระบุจุดผิด แก้ไขภายในช่วงที่ผิด และเพิ่มความน่าจะเป็นของ token ย้อนคิด เช่น Wait, But และ Actually ตอนทดสอบ คำวิจารณ์ช่วยแก้โจทย์คณิตที่การสุ่มตัวอย่างแก้ไม่ได้ แม้บทคัดย่อไม่รายงานตัวเลข

Impact: แนวคิดให้โมเดลวิจารณ์ตัวเองก่อนให้คะแนนอาจช่วยการฝึก reasoning ได้ละเอียดขึ้น แต่บทคัดย่อยังไม่มีตัวเลขผลลัพธ์เชิงปริมาณ
