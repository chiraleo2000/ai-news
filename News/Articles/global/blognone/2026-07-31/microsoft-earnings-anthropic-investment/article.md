# Microsoft รายงานผลประกอบการ รายได้โต 18%, มีกำไรจากการลงทุน Anthropic 3.2 พันล้านดอลลาร์

**แหล่งที่มา:** [Blognone](https://www.blognone.com/node/151262) | **วันที่:** 30 กรกฎาคม 2026

## สรุปข่าว

Microsoft รายงานผลประกอบการไตรมาสล่าสุดด้วยตัวเลขที่น่าประทับใจ โดยมีรายได้รวมเติบโต 18% จากช่วงเดียวกันของปีก่อน ปัจจัยสำคัญที่ทำให้ตัวเลขพิเศษในไตรมาสนี้คือกำไรจากการลงทุนใน Anthropic บริษัท AI safety ที่ Microsoft ได้ลงทุนไว้ก่อนหน้า โดยบันทึกมูลค่ากำไรที่เกิดขึ้นจริง 3.2 พันล้านดอลลาร์สหรัฐ Azure AI Services ยังคงเติบโตอย่างรวดเร็วและเป็นแรงขับเคลื่อนหลักของธุรกิจ Cloud ของ Microsoft น่าสังเกตว่า Microsoft เริ่มแข่งขันกับ OpenAI และ Anthropic อย่างเปิดเผยมากขึ้น โดยพัฒนาโมเดล AI ของตัวเองผ่าน Azure
